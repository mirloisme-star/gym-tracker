# باشگاه

اپ شخصی برای دیدن برنامه تمرین، ثبت ست‌ها و وزن‌ها، ثبت عادت‌های روزانه و دیدن روند پیشرفت. بدون اینترنت کار می‌کنه و همه داده‌ها فقط روی گوشی می‌مونن.

## اجرا روی کامپیوتر

```bash
python3 -m http.server 4173
```

بعد `http://localhost:4173` رو باز کن.

## نصب روی اندروید

1. این پوشه رو روی یک هاست HTTPS استاتیک بذار (مثل GitHub Pages یا Cloudflare Pages). فقط کد اپ اونجا قرار می‌گیره و داده‌ها روی گوشی می‌مونن.
2. آدرس رو توی Chrome اندروید باز کن.
3. از منوی Chrome گزینه Add to Home screen یا Install app رو بزن.

## بک‌آپ

از تنظیمات اپ، بخش بک‌آپ، فایل بگیر و جای امنی نگهش دار. با پاک شدن داده‌های مرورگر یا عوض شدن گوشی، فقط این فایل داده‌ها رو برمی‌گردونه.

## تغییر کد

- بعد از هر تغییر، مقدار `VERSION` توی `sw.js` رو عوض کن تا گوشی نسخه جدید رو بگیره. فایل جدید رو هم به لیست `FILES` همون‌جا اضافه کن.
- برنامه اولیه توی `js/seed.js` فقط بار اول لود می‌شه. بعدش برنامه رو از داخل اپ ویرایش کن.
- مدل سه‌بعدی بدن با `node tools/build-body.mjs` ساخته می‌شه و خروجیش `assets/body.bin` هست.
- تست‌ها با `npm test` اجرا می‌شن.
